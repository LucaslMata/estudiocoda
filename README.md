# Estudio Coda

Landing de **retratos profesionales en estudio** — Ciudad de Buenos Aires.

Sitio estático (HTML + CSS + JS vanilla, sin build step).

## Estructura

- `index.html` — página principal
- `styles.css` — estilos
- `script.js` — interacciones (carrusel, lightbox, aparición al scroll)
- `galeria.js` — lista de fotos de la sección "Trabajos" (editá acá para agregar/reordenar)
- `assets/` — imágenes, favicon, imagen de portada
- `robots.txt`, `sitemap.xml` — SEO

## Cómo se publica

Static Site en **Render** · Build Command: (vacío) · Publish Directory: `.`
